# 🧬 Product Principles (Продуктовые принципы)

> **ДНК Продукта:** Эти принципы определяют, как именно TravelOS решает задачи пользователя. Если фича нарушает хотя бы один из них, она не имеет права на существование.

* **Data before Opinions (Данные важнее мнений):** Мы всегда предпочитаем агрегированные, верифицированные данные единичным субъективным историям с форумов.
* **Reduce Cognitive Load (Снижение когнитивной нагрузки):** Любой интерфейсный экран и любая функция должны уменьшать количество решений, которые пользователю нужно принять в единицу времени.
* **Explain, Don't Hide (Объясняй, а не скрывай):** Мы не просто выдаем пользователю готовое решение («Делай так»). Мы прозрачно объясняем, на основе каких данных и почему система сделала этот вывод.
* **Context over Search (Контекст вместо поиска):** Пользователь получает нужную информацию автоматически в правильный момент и в правильном месте. Он не должен заниматься поиском сам.
* **Community Intelligence (Интеллект сообщества):** Каждая успешно завершенная поездка любого пользователя автоматически делает систему умнее для всех остальных за счет деперсонализированного обогащения Data Platform.
