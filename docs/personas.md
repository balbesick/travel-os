# User Personas — Целевые персоны

Этот документ — результат задачи TRV-003: описать 3–5 User Personas для точного проектирования интерфейса и фич.

---

## 1. Студент‑бэкпэкер (Backpacker Student)
- Кратко: молодой путешественник, ограниченный в бюджете, гибок во времени, ищет дешёвые и аутентичные варианты.
- Демография: 18–28 лет, низкий/средний доход, часто из городов, учится/начинает карьеру.
- Паттерны поведения: планирует спонтанно, использует мобильный телефон, сравнивает цены, ориентируется на советы сообществ и отзывы.
- Главные боли: высокие комиссии, скрытые сборы, сложный поиск локальных событий, плохая мобильная UX.
- Цели использования TravelOS: быстро найти бюджетные экскурсии/хостелы, увидеть отзывы, забронировать с минимальными комиссиями.
- Метрики успеха: время от поиска до брони, конверсия поиска→бронирование, повторные брони.
- Фичи, которые помогают: фильтры по цене, подборки «бюджетных» активностей, рейтинги/отзывы, офферы/скидки для студентов, удобный мобильный checkout.

## 2. Бизнес‑путешественник (Business Traveler)
- Кратко: профессионал с ограниченным временем, важна надёжность и скорость.
- Демография: 30–55 лет, средний/высокий доход, ездит по работе 1–3 раза в месяц.
- Паттерны поведения: планирует заранее, использует мобильные и десктопные приложения, требует интеграций (календарь), ожидает подтверждений и поддержки.
- Главные боли: несогласованные расписания, отмены, длинный процесс бронирования, отсутствие invoices.
- Цели использования TravelOS: быстро забронировать и подтвердить поездку, получить документальные подтверждения и поддержку при отменах.
- Метрики успеха: среднее время брони, процент отмен/rebook, NPS для поддержки.
- Фичи, которые помогают: быстрый Checkout, корпоративные/инвойс-опции, интеграция с календарём, поддержка 24/7, SLA для операций.

## 3. Семья с детьми (Family with Young Kids)
- Кратко: родители, планирующие семейный отдых, важны безопасность и простота.
- Демография: 28–45 лет, средний доход, путешествуют всей семьёй, часто с младшими детьми.
- Паттерны поведения: планируют заранее, сравнивают условия размещения и активности, читают отзывы о семейной пригодности.
- Главные боли: неподходящая инфраструктура (детские кресла, доступность), скрытые условия, сложные политики отмены.
- Цели использования TravelOS: найти безопасные, семейно-ориентированные активности и жильё с понятными условиями.
- Метрики успеха: процент бронирований «семейных» предложений, уровень возврата/отмен, отзывы с отметкой «family‑friendly».
- Фичи, которые помогают: фильтры «подходит для детей», подробные описания инфраструктуры, прозрачные условия возврата, опции страховки.

## 4. Опыт‑искатель / соло‑путешественник (Experience Seeker)
- Кратко: организует уникальные впечатления, готов платить за качество и эмоции.
- Демография: 25–45 лет, средний/высокий доход, ценит аутентичность и опыт.
- Паттерны поведения: ищет уникальные туры, читает блоги и отзывы, бронирует заранее и готов платить премиум.
- Главные боли: однообразные предложения, недостоверные описания, низкий уровень кастомизации.
- Цели использования TravelOS: открыть локальные уникальные активы, легко связаться с гидом, гибкие настройки тура.
- Метрики успеха: ARPU (средний доход на пользователя), процент премиальных бронирований, рейтинг впечатлений.
- Фичи, которые помогают: подборки премиум‑опыта, подробные сторис/галереи, возможность кастомизации тура, верификация гидов и гарантия качества.

---

## Как это связывается с беклогом (быстрая матрица)
- Высокая приоритетность: быстрый и прозрачный Checkout (все персоны), рейтинги/верификация (Backpacker, Experience Seeker), фильтры поиска (Family, Backpacker).
- Средняя приоритетность: корпоративные опции и инвойсы (Business), семейные фильтры и страховка (Family).
- Низкая/дальняя: глубокие персонализации и premium‑сервисы (Experience Seeker) — после базовой надежности и конверсии.

Файл предназначен как исходная точка. Для каждой персоны можно добавить реальные данные (возрастные распределения, target‑страны, доход в локальных валютах) после проведения интервью/аналитики.
